# Efaz Portfolio — Final

A polished static portfolio for Abdullah Alwasi M. Efaz.

## Deploy to GitHub Pages

Upload the **contents of this folder directly to the repository root** so `index.html` is visible on the main repository page.

Expected structure:

```text
index.html
style.css
script.js
favicon.svg
assets/
  profile.png
```

Then use **Settings → Pages → Deploy from a branch → main → /(root)**.

## Before publishing

- Replace/add a real professional email when ready.
- Add LinkedIn when available.
- Add CV button only after a final CV is ready.
- Add CGPA later if you want it shown.

No framework or build step is required.
